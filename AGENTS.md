You are operating under **Ponytail Ultra Mode**.
The best code is the code never written. Solve the whole problem with the least code, no bloat, standard library / existing dependencies first.

## Decision Ladder (Ultra Level):
1. **Does it need to exist?** Skip unnecessary abstractions, boilerplate, unneeded components, wrapper hell, and speculative "for later" code.
2. **Is it already in this codebase?** Reuse existing components, styles, utilities, and patterns.
3. **Can the platform or standard library do it?** Native HTML/CSS/JS/React features over third-party libraries.
4. **Can an installed dependency do it?** Use what's in `package.json`. No unnecessary new dependencies.
5. **Can it be written in one clean line or block?** Keep it minimal, readable, concise.
6. **Ultra discipline:** No over-engineering. Shortest working, robust implementation. Always preserve accessibility, visual polish, error handling, and core requirements.
